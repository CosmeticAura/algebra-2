Unit 2 test day guide

Four blocks, 25 minutes each with a 5 minute break. They go from your weakest topic to the mix. Try each problem on paper before you open the answer.

Know these cold

  • Division is the box backwards. Divisor on the side, quotient on top, remainder is what is left over.
  • Remainder of p(x) ÷ (x − a) is p(a). Remainder 0 means (x − a) is a factor.
  • Factor (x − a) gives a zero at a. The sign flips.
  • Even multiplicity touches, odd crosses.
  • End behavior: even degree both ends match, odd degree they are opposite. Positive coefficient means the right end goes up.
1

Dividing with the box

25 minutes

Read first

  • Division is the box backwards. The divisor goes down the side, the quotient goes on top, and the cells add up to the dividend.
  • Write the dividend with every power. Put a 0 for a missing one: x3 − 7x + 6 is x3 + 0x2 − 7x + 6.
  • Work left to right. For each power ask: what does the dividend need, what does the box already have, and what is the difference? Divide that difference by x to get the next term on top.
  • What is left in the constant spot is the remainder. Check: divisor × quotient + remainder = dividend.
  • Worked example: (2x3 − 3x2 − 8x + 5) ÷ (x − 3) = 2x2 + 3x + 1, remainder 8.

Then try these on paper

1.1 (x3 + 3x2 − 4x − 12) ÷ (x + 3)

Show answerHide answer
  1. Top x2: column x3 and 3x2.
  2. x2 needs 0 more, so the top gets 0x. Nothing to add.
  3. x needs −4x and the box has 0, so top −4: column −4x and −12.
  4. Constant: −12 and −12. Remainder 0.
Answerx2 − 4, remainder 0

1.2 (x3 + x2 − 4x + 6) ÷ (x + 3)

Show answerHide answer
  1. Top x2: column x3 and 3x2.
  2. x2 needs 1 and the box has 3, so it needs −2x2. Top −2x: column −2x2 and −6x.
  3. x needs −4 and the box has −6, so it needs +2x. Top +2: column 2x and 6.
  4. Constant: 6 and 6. Remainder 0.
Answerx2 − 2x + 2, remainder 0

1.3 (3x3 − 5x2 + 2x − 7) ÷ (x − 1)

Show answerHide answer
  1. Top 3x2: column 3x3 and −3x2.
  2. x2 needs −5 and the box has −3, so it needs −2x2. Top −2x: column −2x2 and 2x.
  3. x needs 2 and the box has 2. Needs 0, so the top gets 0.
  4. Constant: the dividend has −7 and the box has 0. Remainder −7.
Answer3x2 − 2x, remainder −7. As a quotient: 3x2 − 2x − 7/(x − 1)

1.4 (x3 − 7x + 6) ÷ (x − 2). Watch the missing x2 term.

Show answerHide answer
  1. Rewrite as x3 + 0x2 − 7x + 6.
  2. Top x2: column x3 and −2x2.
  3. x2 needs 0 and the box has −2, so it needs +2x2. Top +2x: column 2x2 and −4x.
  4. x needs −7 and the box has −4, so it needs −3x. Top −3: column −3x and 6.
  5. Constant: 6 and 6. Remainder 0.
Answerx2 + 2x − 3, remainder 0

Remainder and factor theorem

25 minutes

Read first

  • Factor (x − a), zero at x = a, p(a) = 0 and remainder 0 all say the same thing. The sign flips: factor (x + 5) means the zero is −5.
  • Remainder theorem: dividing p(x) by (x − a) leaves the remainder p(a). Do not divide. Plug in a.
  • Remainder 0 means (x − a) is a factor. Any other remainder means it is not.
  • Find a missing coefficient: plug in the zero, set the result equal to 0, solve for k.

Then try these on paper

2.1 Find the remainder when p(x) = 2x3 + x2 − 5x + 3 is divided by (x − 1).

Show answerHide answer
  1. Plug in 1: 2(1) + 1 − 5 + 3.
  2. 2 + 1 − 5 + 3 = 1.
AnswerRemainder 1

2.2 Is (x + 2) a factor of x3 + 3x2 − x − 6?

Show answerHide answer
  1. (x + 2) means a = −2. Plug in −2.
  2. (−8) + 3(4) − (−2) − 6 = −8 + 12 + 2 − 6 = 0.
  3. Remainder 0.
AnswerYes, (x + 2) is a factor

2.3 Is (x − 3) a factor of x3 − 2x2 − 5x + 7?

Show answerHide answer
  1. Plug in 3: 27 − 18 − 15 + 7.
  2. 27 − 18 = 9, 9 − 15 = −6, −6 + 7 = 1.
AnswerNo. The remainder is 1, not 0

2.4 Find k so that (x − 2) is a factor of x3 − 3x2 + kx + 6.

Show answerHide answer
  1. Plug in 2 and set it to 0: 8 − 12 + 2k + 6 = 0.
  2. Combine: 2k + 2 = 0.
  3. 2k = −2.
Answerk = −1

Factoring and graphs

25 minutes

Read first

  • Pull out the common factor first. Then look for a difference of squares, a² − b² = (a − b)(a + b), or a trinomial: two numbers that multiply to c and add to b.
  • If you know one factor, divide with the box to get a quadratic, then factor that.
  • Four terms? Try grouping: factor the first two, factor the last two, and look for a shared bracket.
  • To sketch: zeros are the x-intercepts. Even multiplicity touches, odd crosses. The y-intercept is the value at x = 0. End behavior comes from the leading term.

Then try these on paper

3.1 Factor x3 − x2 − 6x completely and list the zeros.

Show answerHide answer
  1. Pull out x: x(x2 − x − 6).
  2. Two numbers that multiply to −6 and add to −1: −3 and 2.
  3. x(x − 3)(x + 2).
Answerx(x − 3)(x + 2). Zeros 0, 3, −2

3.2 (x − 1) is a factor of x3 − 2x2 − 5x + 6. Factor it completely.

Show answerHide answer
  1. Divide by (x − 1) with the box. Top x2: column x3 and −x2.
  2. x2 needs −2 and the box has −1, so top −x: column −x2 and x.
  3. x needs −5 and the box has 1, so top −6: column −6x and 6. Remainder 0.
  4. Quotient x2 − x − 6 = (x − 3)(x + 2).
Answer(x − 1)(x − 3)(x + 2). Zeros 1, 3, −2

3.3 Find all zeros of x3 + 2x2 − x − 2 by grouping.

Show answerHide answer
  1. Group: x2(x + 2) − 1(x + 2).
  2. Shared bracket: (x + 2)(x2 − 1).
  3. x2 − 1 is a difference of squares: (x − 1)(x + 1).
Answer(x + 2)(x − 1)(x + 1). Zeros −2, 1, −1

3.4 Sketch f(x) = (x − 3)2(x + 1). Give zeros, y-intercept and end behavior.

Show answerHide answer
  1. Zero at 3 with multiplicity 2: it touches and turns around.
  2. Zero at −1 with multiplicity 1: it crosses.
  3. y-intercept: f(0) = (−3)2(1) = 9.
  4. Degree 3, positive: left end down, right end up.
AnswerCrosses at −1, touches at 3, y-intercept (0, 9), left down and right up

Mixed check, no calculator

25 minutes

Read first

  • Do these on paper with the box and no calculator, the way part one of the test goes.
  • Multiplying: every term times every term, then combine like terms. Subtracting: flip every sign in the second polynomial.
  • Writing an equation from zeros: factor (x − zero) for each one, with the multiplicity as the power. If you are given a point, use it to find the number in front.

Then try these on paper

4.1 Multiply (x + 4)(x2 − 3x + 2).

Show answerHide answer
  1. Box: x · x2 = x3, x · −3x = −3x2, x · 2 = 2x. 4 · x2 = 4x2, 4 · −3x = −12x, 4 · 2 = 8.
  2. x2: −3x2 + 4x2 = x2. x: 2x − 12x = −10x.
Answerx3 + x2 − 10x + 8

4.2 Subtract (4x3 − x + 5) − (x3 + 2x2 − 3x + 1).

Show answerHide answer
  1. Flip the second: −x3 − 2x2 + 3x − 1.
  2. x3: 4 − 1 = 3. x2: −2. x: −1 + 3 = 2. Numbers: 5 − 1 = 4.
Answer3x3 − 2x2 + 2x + 4

4.3 Describe the end behavior of −2x3 + x2.

Show answerHide answer
  1. Leading term −2x3. Odd degree, so the ends are opposite.
  2. Negative coefficient: left end up, right end down.
AnswerLeft end up, right end down

4.4 For f(x) = x(x − 2)3(x + 1)2, give the degree and each zero with its multiplicity and whether it crosses or touches.

Show answerHide answer
  1. Degree: 1 + 3 + 2 = 6.
  2. x = 0: multiplicity 1, odd, crosses.
  3. x = 2: multiplicity 3, odd, crosses (it flattens out as it goes through).
  4. x = −1: multiplicity 2, even, touches.
AnswerDegree 6. 0 crosses, 2 crosses, −1 touches

4.5 Write a polynomial with a zero at 2 of multiplicity 2, a zero at −1, and f(0) = 12.

Show answerHide answer
  1. Start with a(x − 2)2(x + 1).
  2. Plug in 0: a(−2)2(1) = 4a.
  3. 4a = 12, so a = 3.
Answerf(x) = 3(x − 2)2(x + 1)

4.6 Is x2 + 3x−1 a polynomial?

Show answerHide answer
  1. 3x−1 has a negative exponent.
  2. Polynomials only allow exponents 0, 1, 2, 3 and so on.
AnswerNo
