# Algebra 2 study site

Study loop pages for Imagine IM Algebra 2, Unit 2 Section B (polynomials, lessons 5 to 7).

Open it here: https://cosmeticaura.github.io/algebra-2/

Each section: read the notes, take a short break, do the flashcards, brain dump with the notes closed, then mark what you missed. Your progress saves in your own browser.
